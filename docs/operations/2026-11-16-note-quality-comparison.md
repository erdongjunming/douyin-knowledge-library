# 2026-11-16 笔记质量对比：优化前（规则降级）vs 优化后（语义版）

来源：用户对随机样本（傻白《注意力涣散》，aweme 6978749729874218247）的两版笔记的逐维度比对。结论已确认有效。

## 核心结论

- **优化前**更像"可读的学习笔记"：有主题标题、核心观点、详细内容梳理，人读学习可用，但有模板化、高频词垃圾概念、ASR 错词未标注等瑕疵。
- **优化后**更像"结构化证据转储"：atom 编号完整、逐段原文可追溯、机器友好，但语义提炼明显退步——大量重复、空章节、分类错误，甚至把视频明确讲过的"三个方法"标成"视频未提供"。
- **"passed" 标记误导**：格式合规 ≠ 语义合格。语义版的可读性和可用性实际低于规则版。
- 二选一：人读、学习、复用选优化前；审计追溯选优化后；直接发布都不合格，需合成。

## 优化后的具体缺陷

1. 没完成语义提炼：只是把原文拆 atom 后反复归类，缺摘要、方法归纳、风险边界。
2. 分类错误：核心三类方法（主动无聊/舒尔特方格、切换场景、声音辅助）被标"未提供"。
3. 空章节过多：关键概念、金句、理解、可执行行动、证据与局限。
4. passed 误导；5. 重复膨胀。

## 优化前的具体缺陷

1. 关键概念是高频词机械抽取（"beats""这种需求"）。
2. 金句/行动项模板化。
3. ASR 错词未标注（"数尔特方格"→疑"舒尔特方格"、"挥化"、"傻白熊"、"派里"）。
